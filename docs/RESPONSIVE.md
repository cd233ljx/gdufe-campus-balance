# 窗口适配与验证

布局以应用窗口的可用宽度为依据，不按显示器英寸建立固定模板。

- 初始窗口以 920 × 760 逻辑像素为目标，按 Tk 的当前字体缩放计算物理尺寸，并限制在显示器工作区内；保留用户调整后的窗口位置和大小。
- 首页宽度跟随视口。卡片根据缩放后的最小可读宽度排列，空间不足时换行；操作按钮和首次设置选项自动换行。
- 文字按容器宽度折行。主窗口底部操作区固定，内容超出高度时纵向滚动。其他包含宽表格的页面可保留必要的横向滚动。
- 滚动条仅在内容超出时显示，不以隐藏横向滚动条来掩盖首页内容越界。

## 自动化验收

`tests/test_responsive_layout.py` 在真实 Tk 窗口中使用模拟账户，覆盖首次设置和三个余额项目的首页。

| 项目 | 覆盖 |
| --- | --- |
| 目标分辨率 | 1366×768、1920×1080、1920×1200、2560×1440、2560×1600 |
| 字体缩放 | 100%、125%、150%、175%、200% |
| 手动调整窗口 | 1000×900、800×600、640×480、480×640 |
| 检查 | 首页无横向溢出，控件在视口内，文字与按钮宽度足够，底部操作按钮可见 |

共 90 个页面 / 尺寸 / 缩放组合。分辨率通过限制可用尺寸模拟，缩放通过 Tk 字体缩放模拟；这不等同于在所有实体显示器和 Windows DPI 配置上的实测。打包版另运行完整普通窗口、小屏界面回归。

当前应用使用系统 DPI 感知。跨不同 DPI 显示器拖动时的实时 DPI 切换尚未完整验收，不声称已实现 per-monitor-v2 支持。
