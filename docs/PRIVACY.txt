广财校园工具箱隐私说明（使用统计）

本软件由个人维护，与学校及校园卡平台无隶属关系。余额查询、校园网登录、邮箱提醒所需的账号配置、余额和查询历史保存在当前 Windows 用户的本机加密目录中。软件的核心功能不要求参与使用统计。

交互式安装时“参与使用统计”选项预先勾选，你可以取消；静默安装不会自动参与。安装后也可在“设置 → 使用统计与隐私”中更改。未参与时不会上传统计事件。参与后，请求正文仅包含随机生成的统计编号、软件版本、日期，以及固定类型的事件：参与统计、主动打开、完成配置、关注的功能、查询成功、低额提醒送达。统计用于衡量软件使用和功能效果；请求正文不会包含姓名、学号、房间、余额、手机号、邮箱、密码、授权码或学校登录凭证。

统计请求通过 metrics.utopiacd.online 的 Cloudflare Tunnel HTTPS 入口送达开发者服务器。网络传输时，Cloudflare 可能处理 IP 地址等连接信息；本项目的统计数据库不保存 IP 地址。服务端原始事件保留最近 365 个自然日，并定期清除过期事件；客户端未发送的事件最多保留 30 天、最多 500 条。随机编号用于同一设备上的事件去重和统计，不能据此证明真实使用人数或学生身份。

你可在“设置 → 使用统计与隐私”中停止参与并申请删除已上报记录。离线时删除请求保存在本机，网络恢复后重试。关闭统计不影响软件的余额查询、提醒或校园网功能。问题及个人信息处理请求可通过项目 Issues 联系维护者：https://github.com/cd233ljx/gdufe-campus-balance/issues 。
